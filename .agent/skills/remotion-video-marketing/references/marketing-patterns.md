# Marketing Patterns for Remotion Scenarios

This document contains detailed breakdowns of marketing psychological frameworks to be used when writing Remotion video scenarios.

## 1. PAS (Problem, Agitation, Solution)
Best for SaaS, digital tools, and service-based software.
- **Problem (0-3s):** Immediately state or visually highlight the exact pain point the user faces. No introductions, no logos—just the problem.
  - *Example:* A screen recording of a chaotic, disorganized spreadsheet with a frustrated sigh sound effect.
- **Agitation (3-7s):** Twist the knife. Show the consequence of the problem (lost time, lost money, frustration).
  - *Example:* Text slamming onto screen: "Another 3 hours wasted?" combined with a rapid montage of error notifications.
- **Solution (7-15s):** Introduce the UI/UX of the project being developed as the seamless, magical fix.
  - *Example:* "Spring" the new dashboard design into view. Show a clean, organized state.
- **Call to Action (15s+):** Clear next step. "Get Early Access" or "Try it Free."

## 2. AIDA (Attention, Interest, Desire, Action)
Best for physical products, e-commerce, and visually striking apps.
- **Attention (Hook, 0-2s):** Pattern interrupt. A visually stunning transition, a bold claim, or a highly satisfying UI motion.
- **Interest (2-6s):** Highlight a unique feature of the product. Show, don't just tell.
- **Desire (6-12s):** Show transformation or lifestyle integration. This is where user testimonials or "after" states come in. Use the project's premium design elements to build trust.
- **Action (12s+):** Direct the user to the website or app download.

## 3. The Feature-Advantage-Benefit (FAB) Stack
Used when highlighting specific component functionalities derived from the repository.
- **Feature:** "Our app features a real-time calendar." (Show the Calendar component).
- **Advantage:** "It syncs with Google instantly." (Show the API integration loading state).
- **Benefit:** "Never double-book a meeting again." (Show a success toast notification).

## Copywriting Tips for Video Scripts
- Keep it punchy. People read slower on video.
- Use kinetic typography for emphasis on action verbs.
- Pair motion with emotion: Fast spring animations for energy/excitement, slow ease-in/out for luxury/premium feel.
