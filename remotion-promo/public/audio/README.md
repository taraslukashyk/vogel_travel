# Audio assets

The promo composition expects the following audio files. All are **optional**
during development — the `<SoundBed>` component defaults to `enabled={false}`
and renders silence. Enable it in the composition schema once files are in place.

## Required tracks

| File                 | Role                                      | Source suggestions                 |
| -------------------- | ----------------------------------------- | ---------------------------------- |
| `music.mp3`          | Background bed — cinematic uplifting      | Pixabay / Epidemic Sound / Artlist |
| `sfx/whoosh.mp3`     | Scene-transition whoosh                   | Freesound / Zapsplat               |
| `sfx/key.mp3`        | Keyboard key tick for typewriter cadence  | Freesound                          |
| `sfx/click.mp3`      | UI click / tap                            | Freesound                          |
| `sfx/sms-chime.mp3`  | iOS-style SMS notification for scene 7    | Freesound                          |

## Licensing

Use royalty-free sources with commercial licensing suitable for a travel-brand
marketing video. Swap these placeholders with licensed tracks before shipping.
